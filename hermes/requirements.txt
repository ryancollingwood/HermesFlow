# Extra Python packages baked into the Hermes venv at image-build time.
#
# WHY THIS FILE EXISTS: the upstream nousresearch/hermes-agent image disables
# runtime lazy installs (HERMES_DISABLE_LAZY_INSTALLS=1) AND ships a read-only,
# root-owned venv, so the agent cannot pip-install at runtime. We instead bake
# packages in as root at BUILD time, then re-lock the venv (see hermes/Dockerfile).
#
# RULES:
#  - Pin EXACTLY to the version in Hermes' LAZY_DEPS allowlist (tools/lazy_deps.py)
#    so ensure("<feature>") sees the feature as already satisfied and never hits
#    the disabled install path. A mismatched pin makes Hermes try (and fail) to
#    install at runtime.
#  - One spec per line. No URLs / git+https / local paths / --index-url overrides.
#  - After changing this file, redeploy with:
#        docker compose build hermes && docker compose up -d hermes
#  - See docs/hermes-docker-build.md for the full process and rationale.
